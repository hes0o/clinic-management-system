# 🏥 Clinic Management System

> A comprehensive digital healthcare management platform for handling patient records, doctor scheduling, and appointment booking.

---

### 🚀 Key Features
* **Role-Based Dashboard:** Secure portals tailored for Admins, Doctors, and Receptionists/Patients.
* **Appointment Scheduling:** Streamlined booking system with conflict prevention and time-slot management.
* **Patient Records Management:** Secure CRUD operations for patient medical histories, prescriptions, and billing.
* **Search & Filter:** Quickly look up patients or doctors by department, name, or availability.
